# Resolved synthetic charging-geography evidence

Raw answers and all owner/cohort memberships are preserved. Only exact canonical names and existing declared aliases are resolved, using case and whitespace normalization. No fuzzy matching or new aliases are introduced. The registry files are recorded as input snapshots and canonical identities checked against the hash-bound profile index; the registry report is retained as a source reference, without assuming its provenance schema.

Not applicable, blank and unresolved text are separate answer states. A non-district answer does not identify a zero probability of outside charging. Equal home/outside districts remain visible review flags. The no-away check compares Q20 with reported non-home frequency bounds; it changes no eligibility.

Groups overlap and must not be added. District-pair tables count owners reporting a most-common district, not sessions or energy flows. Q20/Q21 do not establish per-context routing probabilities. T1/T2/T3/T4 remain verified survey contexts, without automatic geographic place-typology mappings.

This step performs no imputation, new parameter draws, demand simulations, fleet activation or empirical validation.
